# Carrera Beach — web (muestra)

Página única (`index.html`) para Carrera Beach, resto-bar en Villa Gesell. Sin publicar.

- Configurar el número de WhatsApp en la constante `WHATSAPP` al final del archivo (mientras esté vacío, los botones abren el chat de Instagram).
- Fotos de muestra de Wikimedia Commons (licencias libres): reemplazar por fotos propias del local en `img/`.
